# Singhaya Online Project Delivery Workflow

## Purpose

This document defines the standard workflow for delivering client projects and monthly services under Singhaya Online.

The goal is to make work clear, repeatable, trackable, and ready for future team expansion.

---

## 1. Project Intake

When a client confirms interest, collect the following information:

- Business name
- Contact person
- Main problem
- Current online channels
- Service needed
- Budget range
- Timeline
- Access requirements
- Existing brand assets
- Urgency level

Use the client onboarding SOP as the main reference:

```text
docs/sop-client-onboarding.md
```

---

## 2. Client Folder Setup

Create a client folder under:

```text
clients/client-name/
```

Recommended files:

```text
clients/client-name/
├── brief.md
├── proposal.md
├── content-plan.md
├── access-note.md
├── change-log.md
└── monthly-report.md
```

Do not store passwords or confidential data in GitHub.

---

## 3. Proposal & Scope Confirmation

Before starting work, confirm:

- Scope of work
- What is included
- What is not included
- Monthly fee or project fee
- Payment terms
- Timeline
- Communication channel
- Client responsibilities
- Approval process

All additional work outside scope must be quoted separately.

---

## 4. Kickoff Checklist

Before work starts:

- Confirm payment or deposit
- Confirm start date
- Create client folder
- Create client brief
- Create proposal file
- Prepare content plan
- Confirm access status
- Confirm main contact person
- Add client to sales pipeline
- Add client to revenue tracker if active

---

## 5. Monthly Delivery Workflow

For monthly clients, follow this cycle:

### Week 1

- Review business needs
- Confirm monthly content direction
- Prepare content topics
- Check website or online channels
- Confirm priority tasks

### Week 2

- Create / update content
- Support online communication
- Update website or digital assets if included
- Review customer inquiry flow

### Week 3

- Monitor response
- Adjust content direction
- Prepare campaign ideas
- Support event or promotion communication

### Week 4

- Prepare monthly summary
- Review completed tasks
- List pending tasks
- Recommend next month plan
- Confirm next month payment / renewal status

---

## 6. Quality Control

Before delivering any work, check:

- Brand consistency
- Spelling and grammar
- Correct contact information
- Correct links
- Correct pricing or offer details
- Mobile readability
- Image quality
- Client approval if required

---

## 7. Communication Rule

Use clear written communication with clients.

Recommended channels:

- LINE
- Email
- WhatsApp
- Shared Google Drive
- GitHub for internal documentation only

Do not rely only on verbal agreements. Important changes should be written down.

---

## 8. Change Log Rule

Every important update must be recorded in the relevant change log.

Internal master change log:

```text
docs/change-log.md
```

Client-specific change log:

```text
clients/client-name/change-log.md
```

---

## 9. Delivery Philosophy

Singhaya Online should deliver work that is:

- Clear
- Useful
- Organized
- Professional
- Sustainable
- Easy for clients to understand
- Easy for future team members to continue

---

## 10. Future System Expansion

This workflow can later expand into:

- CRM pipeline
- Ticketing system
- Client dashboard
- Automated monthly reports
- Booking system
- Course platform
- Certificate system
- AI-assisted content workflow
